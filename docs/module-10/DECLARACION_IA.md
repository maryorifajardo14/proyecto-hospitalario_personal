Utilicé a Gemini (IA) para entender el uso de Git Worktree, estructurar el documento Markdown y apoyar la definición de los actores del diagrama.

Para las entregas de las Semanas 1, 2 y 3 también usé Claude (Claude Code) de forma puntual y no intensiva, como apoyo de revisión y redacción: verificar que cada entrega cumpliera exactamente lo pedido en el plan semanal para mi módulo, ordenar el contenido, y ayudar a redactar las tablas de RF/RNF, criterios de aceptación, el ejemplo del principio SOLID y el diagrama de componentes, siempre a partir de los casos de uso y del código ya existente en el repositorio (modelos, migraciones, middleware y roles).

En todos los casos la intervención de la IA fue puntual y bajo supervisión humana constante: yo revisé, validé y ajusté cada cambio antes de aceptarlo. La elaboración final de los diagramas, el análisis del módulo y las decisiones de contenido son de mi autoría.
